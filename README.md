# Conductor-or-Parrot
Half live by Hackclub PCB beginner project (WIP)

A small standalone Board that able to connect to various extensions in the future to be able to perform assisting Work for other projects as a little droid like helper. The board itself is a standalone device with expression interface in form of a display, a camera for visibility, a speaker and a powerful enough micro controller to be able to do object detection task simple calculations and other assistance. In the future it should be able to connect to extensions like wheels or other movement, a robot arm or a desktop connection to be able to perform admin tasks in the workflow
